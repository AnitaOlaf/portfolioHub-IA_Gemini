# portfolioHub-IA_Gemini. 
📁 Portfolio Hub + IA Gemini
Portfolio Hub é um espaço centralizado para organização e apresentação de projetos de desenvolvimento, com um diferencial inteligente: a integração com a IA Gemini.

A solução utiliza o modelo do Google Gemini para atuar como uma curadoria automatizada: geração de resumos descritivos dos projetos, sugestão de tags de categorização, respostas a perguntas sobre o portfólio e recomendações personalizadas de projetos conforme o perfil do visitante.

O objetivo é transformar a navegação em uma experiência interativa, acessível e orientada por inteligência artificial, mantendo o foco na clareza técnica e na qualidade da informação apresentada.
